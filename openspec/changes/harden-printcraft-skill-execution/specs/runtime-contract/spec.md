## Purpose

定义固定原生运行时的诊断、安装、能力身份和进程生命周期，使技能在首次使用及复用时能区分只读发现、授权安装和真实兼容性，避免把源码或锁文件声明误作执行证据。

## ADDED Requirements

### Requirement: RT-01 只读诊断与安装分离

系统 SHALL 提供不会创建运行时目录、下载、改 PATH 或修改配置的诊断方式；安装操作遵守当前会话已有授权，不重复请求已有授权，不从只读请求推导安装授权。

#### Scenario: 缺失环境诊断
- **WHEN** 运行时未安装且用户仅要求诊断
- **THEN** 返回缺失依赖、平台和可执行后续动作，文件系统与网络下载均不发生变更。

#### Scenario: 已授权安装
- **WHEN** 用户已授权必要运行时安装
- **THEN** 执行固定制品校验安装或复用，不再要求同一授权。

### Requirement: RT-02 固定制品与名称兼容

系统 SHALL 保留归档/二进制摘要、版本输出、发行地址/tag/资产名称的一致性验证；分别管理 printcraft-cli 与 pdfcraft-cli 的运行时目录，不迁移旧数据、不降级校验、不自动升级。

#### Scenario: 身份错配
- **WHEN** tag、资产名称、摘要或版本输出任一与锁不符
- **THEN** 拒绝安装或复用并保留旧运行时；不得以本地同名 PATH 程序替代。

#### Scenario: 新旧名称共存
- **WHEN** 新增已核实的 PdfCraft 制品且旧 PrintCraft 目录存在
- **THEN** 新身份独立安装，旧数据与安装记录不变，分别报告能力。

### Requirement: RT-03 实时能力及离线边界

系统 SHALL 将实际可执行文件摘要、版本、平台和目录摘要绑定到执行证据；离线 catalog 只用于 list/describe/check，run 必须重新发现并验证实际工具与受支持 Schema 子集。

#### Scenario: 离线执行请求
- **WHEN** run 传入离线 catalog
- **THEN** 在原生编辑前拒绝，不将离线检查结果当成实际能力授权。

#### Scenario: 目录不兼容
- **WHEN** 真实 Schema 包含未知约束或运行时身份改变
- **THEN** 给出结构化兼容错误，不忽略约束或沿用旧目录检查结果。

### Requirement: RT-04 短任务和长驻服务生命周期

系统 SHALL 为查询、编辑、渲染及 MCP 服务区分时间策略；长驻服务不得继承统一 600 秒业务截止，显式超时/终止/传输 EOF 应有可观察结果，原生 stdout/MCP 协议流不得混入包装器 JSON。

#### Scenario: MCP 超过短任务时限
- **WHEN** 健康 MCP 服务存活时间超过普通短任务截止
- **THEN** 保持服务直到协议 EOF、授权停止或明确服务策略触发，协议消息不受污染。

#### Scenario: 短任务超时
- **WHEN** 编辑达到配置截止
- **THEN** 保留部分诊断并输出结果未知，不声称所有后代进程已停止或文件已回滚。
