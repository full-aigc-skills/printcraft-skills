# 页面编辑案例

1. 成功：用户说“页面编辑并另存结果”；记录输入和授权，先 diagnose/list/describe，单会话执行，按输出清单新进程重开；执行成功只记待审阅，内容与视觉通过才接受。
2. 失败：运行到第二步超时，第一步可能已写出 PDF。保存 UNKNOWN 回执，执行 status/reconcile，检查现存文件和摘要；不重放，不沿用旧 doc ID。
3. 拒绝：离线目录被用于 run、未知 Schema、输出已存在或原件覆盖超出授权。编辑前拒绝，保留已有文件；明确缺少的范围或环境，修正新候选后再运行。

自然语言路径按本技能 description；显式 $printcraft-cli-pages 直接使用本入口，不强迫先经过总入口。页面任务额外验证页序、旋转和页框，检查任务遇空文本保留扫描件分类。
